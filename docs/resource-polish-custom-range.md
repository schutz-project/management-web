# 리소스 카드 정렬과 사용자 지정 기간

## 화면 요청 반영

1. 자원 카드의 제목·상태 배지를 동일한 행 구조로 배치해 루트 디스크의 현재값·그래프가 아래로 밀리지 않도록 정렬합니다.
2. 현황 헤더의 수집 배지는 제목·대상 주소 옆, 상세보기는 오른쪽에 배치합니다.
3. 상세 통계에 현재값(⏱️)·평균값(📊)·최대값(📈)·최소값(⬇️)·변동 폭(↕️) 아이콘과 배경색을 추가합니다. 아이콘은 장식이며 텍스트 레이블도 유지합니다.
4. 화면의 24시간 표기를 1일로 바꾸고 사용자 지정 달력·시간 선택을 제공합니다. API의 기존 24h 키는 유지합니다.

## 실제 사용자 지정 조회

- 한국 시간(KST) 시작·종료 일시를 선택하고 시간대가 명시된 ISO 시각으로 서버에 전달합니다.
- 최근 7일 안의 최소 1분~최대 1일 구간으로 제한합니다. 실제 데이터가 없으면 없음을 표시합니다. 보존 설정을 변경하지 않습니다.
- 서버도 시간대·순서·길이·미래 시각·보존 범위를 검사합니다. 관리자 인증 후에만 조회합니다.
- 고정된 기존 PromQL·LogQL을 재사용하며 반환 시계열은 최대 300점으로 제한합니다. 사용자 지정 캐시는 마지막 구간 1개만 보존합니다.
- 지표는 선택 구간을 조회합니다. 사건·현재 경보·수집 대상·최근 5분 로그는 현재 조회 기준을 유지하고 화면에서 차이를 안내합니다.
- 과거 자원 값은 현재값이 아닌 선택 종료 시점 값으로 표시합니다. 수집 상태도 선택 시점 기준임을 구분합니다.
- 긴 평가 간격의 마지막 표본을 고정 60초 기준으로 잘못 누락시키지 않도록 해당 그래프 간격도 고려합니다. 원본 계측 최신성 검사는 별도로 유지합니다.
- 기간은 URL에 저장하고 뒤로가기·새로고침으로 복원합니다. 사용자 지정에서는 자동 갱신하지 않습니다.
