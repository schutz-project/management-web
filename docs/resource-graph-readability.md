# 서버 리소스 그래프 가독성 개선

- CPU·메모리·루트 디스크의 현재 사용량을 0~100% 막대로 표시합니다.
- 추이 선을 굵게 하고 옅은 면적과 끝점 표시를 추가합니다.
- 기본 축은 0~100%입니다. 변화 확대는 관측 최솟값·최댓값 주위에 여백을 추가하며 실제 축 범위를 표시합니다. 확대 상태가 고부하를 뜻하지 않음을 안내합니다.
- 시각별 수치는 그래프 위 포인터 또는 키보드로 조작 가능한 범위 입력으로 확인합니다. 별도 조회를 발생시키지 않습니다.
- 결측·긴 수집 간격은 선을 끊습니다. 표본이 1개면 변화 판단 불가, 값이 일정하면 변화가 거의 없다는 안내를 표시합니다.
- 변화가 거의 없다는 문구는 표시 표본의 최대·최소 차이가 0.1%p 미만일 때의 설명이며 장애 임계치가 아닙니다.
- 원본 데이터, 기간별 조회 API, 인증·조회 전용 정책, Worker·DB·배포 설정은 변경하지 않습니다.

검증: 기존 UI 시험을 포함한 Node 회귀 시험 20개. 축 전환·실제 수치 유지·시각별 조회·누락 구간·상수값·결측 처리를 포함합니다. 실제 브라우저의 최종 시각 검토는 별도로 수행합니다.
