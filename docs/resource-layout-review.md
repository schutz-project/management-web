# 서버 리소스 현황·상세 역할 분리

## 반영 내용

- 현황: CPU·메모리·루트 디스크 3열, 기존 아이콘·색상 유지. 큰 현재값과 표시 표본 평균·최대, 작은 추이 그래프로 압축합니다.
- 현황의 중복 사용량 막대·슬라이더·시각별 수치·긴 안내를 제거하고, 공통 하단에 조회 시각·평가 간격·전체/확대 전환을 배치합니다.
- 각 카드의 상세 버튼은 해당 자원의 상세 화면으로 연결합니다.
- 상세: 자원 탭과 큰 그래프 하나, 현재·평균·최대·최소·표본 변동 폭을 제공합니다. 탭은 방향키·Home·End로 이동할 수 있으며 선택 자원은 URL과 뒤로가기로 복원합니다.
- 확대 여부는 상세의 자원별로 독립 유지합니다. 현황은 공통 전환입니다.
- 상세의 포인터·키보드 시각 선택과 그래프 선택 지점 동기화를 유지합니다.
- 메트릭 수집 정상과 수집 지연·조회 실패·데이터 없음을 구분하며 사용률 위험 상태나 서비스 전체 정상으로 해석하지 않습니다.
- 과거 데이터가 남아도 수집 지연 상태에서 현재 사용률을 최신값처럼 표시하지 않습니다.

## 데이터 해석

평균·최대·최소·변동 폭은 선택 기간에 API가 반환한 유효 표시 표본 기준입니다. 변동 폭은 퍼센트포인트(%p)이며 기간 전체의 원시 데이터 변동 폭을 보장하지 않습니다.

API의 `as_of`는 조회 평가 시각, `step_seconds`는 그래프 평가 간격입니다. 실제 마지막 수집 시각·수집 주기로 오인하지 않도록 그대로 이름을 구분합니다. 상세의 마지막 유효 표본 시각 또한 원본 수집기 실행 시각을 뜻하지 않습니다. API 지원 기간(15분·1시간·6시간·24시간)과 기존 상단 기간 선택은 유지하며 사용자 지정 기간은 추가하지 않습니다.

## 범위와 검증

UI·테스트·문서만 변경합니다. AWS/Terraform, Compose/Docker 배포 설정, Prometheus·Alloy, 인증·API·DB·Worker는 변경하지 않습니다.

Node UI 회귀 시험 24개 통과. 현황 압축·상세 탭·자원별 축 전환·키보드·URL 이력·통계·지연·결측을 검사합니다. 실제 브라우저의 최종 배치와 화면 확인은 별도로 수행합니다. 병합·배포는 사용자 승인 후 진행합니다.
