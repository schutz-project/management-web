# 사용자 최종 시안: 서비스 상태·상세 화면

## 반영 범위

- FastAPI·PostgreSQL·Nginx 카드를 같은 높이와 정보 순서로 구성합니다. 상단 아이콘·대상·기능 점검 배지, p95 값, 실제 추이, 두 개 보조 지표, 기간·조회 시각, 상세 이동 순서입니다.
- FastAPI 파랑(#087dff), PostgreSQL 보라(#8b5cf6), Nginx 청록(#14b8a6)을 사용합니다. 상태 배지 색상은 별도입니다.
- Loki는 세 서비스와 의미가 다르므로 별도 조회 상태 영역과 로그 분석 링크로 보존합니다. 표시 건수는 API가 반환한 제한된 최근 로그 건수입니다.
- 서비스 탭·대형 차트·전체/확대·포인터/키보드 시각별 수치와 실제 표시 표본의 평균·최대·최소·표준 편차를 제공합니다. 기존 경로별 세부 지표 표도 보존합니다.
- 이전에 지적받은 리소스 통계의 플랫폼 이모지도 동일한 선형 SVG 아이콘으로 교체합니다. 로고·기존 리소스 아이콘·계측값은 유지합니다.

## 실제 데이터와 상태 의미

- FastAPI p95는 `portal_http_duration_bucket`, 앱 DB 작업 p95는 `portal_db_duration_bucket`에서 각각 계산합니다. 현재 API의 서로 다른 PromQL·히스토그램을 그대로 사용하며 동일 수치가 나와도 하나의 지표로 합치지 않습니다.
- Nginx 핵심 수치는 Loki의 `/health` 경로 `request_time` p95이며 초→ms로 변환합니다. 요청·5xx도 해당 경로만 표시합니다. 경로 표본이 없으면 오류 0으로 만들지 않습니다.
- PostgreSQL 연결 수·활성 세션은 수집 구현 전까지 미수집입니다.
- 배지는 기존 `/api/dashboard`의 현재 기능 점검 결과를 사용합니다. 정상은 정상, 지연·미확인은 점검 미확인, abnormal은 점검 이상으로 표시합니다. 현재 API만으로 주의와 장애를 정확히 나눌 수 없으므로 임의 임계치를 추가하지 않습니다. 지표 조회 실패와 기능 점검 정상은 별개로 표시합니다.
- 카드·차트의 조회 시각 및 KST를 표시합니다. 실제 수집 시각이 제공되지 않는 지표에 조회 시각을 수집 시각으로 표시하지 않습니다. 기능 점검에는 API가 제공한 `last_checked_at`을 표시합니다.
- 임의 진폭·곡선·증감률·SLO 임계치를 만들지 않습니다. 고정된 값은 그대로 평평하게 표시합니다.
- 표준 편차는 유효한 구간별 p95 표시 표본의 모집단 표준 편차입니다. 전체 HTTP 요청 분포나 기간 전체의 요청 p95를 뜻하지 않습니다. 유효 표본 수와 해석을 함께 표시합니다.
- 과거 사용자 지정 지표와 현재 기능 점검은 별도로 안내합니다. 서비스별 기간과 기존 달력 기능은 유지합니다.

## 검증·제한

Node UI 회귀 시험 33개: 카드 구조·색상·실측 연결·미수집·누락 경로·기능/수집 상태 구분·상세 이동·탭·축 모드·시각별 조회·표본 통계·결측 단절·선형 아이콘 등을 검사합니다. 실제 브라우저의 최종 배치·반응형 확인은 별도로 수행합니다.

API·계측·수집·DB·Worker·AWS·Terraform·Compose·CI/CD 설정은 변경하지 않습니다. 사건·로그의 시점별 상관 조회, 이전 기간 대비 증감률과 신규 수집은 별도 후속 항목입니다.

## 통계 아이콘 시안 누락 보완

현재·평균은 파랑 원형 배경, 최대는 분홍 배경·빨강 상승 화살표, 최소는 연청록 배경·청록 하강 화살표, 표준 편차는 연보라 배경·보라 Σ로 구분합니다. 현재값 옆에는 해당 값의 마지막 유효 표본 시각(KST)을 표시하며, 데이터가 없으면 시각을 만들지 않습니다. 리소스 통계에도 같은 아이콘 색상 체계를 적용합니다. 보완 후 UI 회귀 시험은 34개입니다.
