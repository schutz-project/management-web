# 사건 상세의 현재 근거·과거 조치·AI 설명 구분

## 변경 범위

과거 이력 활용 검증 및 UI 개선 요구사항에 따라 사건 상세를 개선합니다. Web의 정적 화면과 테스트만 변경하며 Worker·API 응답 계약·DB·네트워크·환경 설정은 수정하지 않습니다. 기존 로고·색상·아이콘·화면 이동과 관리자 접수·조치·종료 조건을 유지합니다.

1. **현재 사건의 분석 입력 근거**: 해당 AI 작업의 input_evidence 중 현재 근거를 표시합니다. 표본 시각·출처·상태 코드·점검 결과와 근거 ID를 직접 사용합니다. AI 문장을 사실로 변환하지 않습니다.
2. **참고한 과거 사건**: historical_context 입력의 조치 내용을 별도 카드에 표시합니다. 실제 저장된 입력 ID와 응답 evidence_ids를 기준으로 참고·인용 건수를 계산합니다. 첫 카드는 펼치고 나머지는 접습니다. 카드 최대 3개, 조치 최대 3개·각 500자입니다.
3. **AI 설명·가설과 확인 사항**: 저장된 summary·hypotheses·next_checks·limitations와 인용 ID를 표시하며, 사실·기간·원인 판단을 원본과 대조해야 한다고 안내합니다.

최초 모듈은 저장된 데이터를 해석하는 순수 함수로 구성합니다. 자체 네트워크 요청이나 상태 변경을 하지 않습니다. 현재 탐지 근거 전체와 접수·조치 이력은 기존 영역에 유지합니다.

## 누락·인용·원본 링크

- input_evidence 미제공과 빈 입력을 구분합니다. 이력 없음의 원인을 기능 비활성화로 단정하지 않습니다.
- 결과의 evidence_ids가 아직 없으면 인용 수는 미확인입니다. 명시적으로 현재 근거만 인용했다면 과거 인용 0건과 미인용 안내를 제공합니다.
- 입력·인용 ID는 중복 제거해 계산합니다. 실제 참고 건수가 아닌 최대 설정값 3을 고정 표시하지 않습니다.
- 원본 이동은 history:<전체 UUID>와 payload.incident_id가 일치할 때만 제공합니다. 축약·위조·자기 자신 ID는 정상 원본 링크로 만들지 않습니다.
- 입력에 없는 인용은 출처 미확인으로 표시합니다. AI 문장 속 사건 번호를 파싱해 링크를 만들지 않습니다.
- 원본 상세 버튼은 기존 관리자 상세 조회를 사용합니다. 뒤로가기로 원래 사건 상세를 복원합니다. 조회·펼치기·이동으로 AI 호출·Slack 발송·사건 쓰기를 실행하지 않습니다.
- 조치 문장은 textContent로 표시하며 HTML을 실행하지 않습니다.

## 시각과 관측 범위

종료된 사건은 과거 사건 분석으로 표시합니다. 탐지 시각·종료 시각과 저장된 AI 결과의 성공한 시도 완료 시각을 구분합니다. 완료 시각이 미제공이면 사건 시각으로 대체하지 않습니다. 모든 표시 시각은 KST입니다.

탐지~종료 소요 시간은 원본 두 시각이 유효하고 시간 순서가 맞을 때 계산합니다. 이는 실제 오류 지속 시간과 다르다고 명시합니다. AI 요약의 “약 12분” 같은 문장을 계산 근거로 사용하지 않습니다. 이번 변경은 오류 표본의 연속 구간이나 실제 중단 시간을 새로 판정하지 않습니다.

MonitoringTargetDown의 up=0은 메트릭 수집 실패이며 서비스·컨테이너 중단은 별도 점검으로 확인해야 한다고 설명합니다. 과거 조치는 현재 원인이나 과거 조치 효과를 입증하지 않습니다.

## 운영 데이터 표시 시 주의

앞서 수행한 실제 과거 이력 AI 진단은 기존 사건의 결과를 수정하지 않았습니다. 따라서 그 진단 결과가 기존 사건 UI에 자동으로 나타나지는 않습니다. 화면은 각 작업에 실제 저장된 input_evidence를 표시합니다. 기능 활성화 후 새로운 AI 작업에 이력이 저장되어야 해당 사건에서 참고 카드를 볼 수 있습니다. 기존 사건 재분석·결과 소급 저장은 이번 PR에서 실행하지 않습니다.

과거 기록이 화면에 없다는 이유만으로 새로운 장애를 반복 발생시키지 않습니다. 테스트 fixture로 표시·링크·인용을 검증하고 운영 데이터 확인은 승인된 별도 검증으로 진행합니다.

## 검증

Node 기반 DOM 테스트 49개가 통과했습니다. 기존 41개에 현재/과거/가설 분리, 원본 이동과 뒤로가기, 미제공/빈 입력/미인용, 결과 대기, 시각 계산, 위조 ID·HTML 비실행, 수집 범위 설명, 중복 제거·접힘 상태 8개를 추가했습니다. 기존 관리자 처리·CSRF 요청·조회 전용 정책도 회귀 시험으로 유지합니다.

실제 브라우저의 배치·글꼴·모바일 시각 검수와 운영 데이터의 표시 확인은 아직 완료 판정하지 않습니다. CSS는 기존 색상과 반응형 구성을 확장하며 작은 화면에서는 시각 정보를 한 열로 배치합니다.
